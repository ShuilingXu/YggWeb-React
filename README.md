# YggWeb-React

YggServer-Go 的独立 React 前端。信息架构与操作关系参考 [Blessing Skin](https://github.com/bs-community/blessing-skin-server)，采用 Minecraft 草地、泥土与石块色系、像素插画、方形按钮和硬边阴影。浅色/深色主题、手机抽屉导航、中文文案、会话恢复和错误反馈均已接入。

## 当前实现

| 页面 | 行为 |
| --- | --- |
| 公开首页 | 独立首页、像素场景、功能介绍与三步接入；匿名进入注册，登录后进入用户中心；不显示用户侧栏 |
| 皮肤库 | 经典/纤细/披风分类，名称、上传者 UUID、排序与分页；筛选状态存于 hash URL |
| 材质详情 | 鉴权平面预览、公开皮肤懒加载 3D、自动旋转开关、原图下载、收藏、选择角色穿戴 |
| 材质管理 | 上传 PNG、尺寸与模型校验、名称/模型/隐私编辑、本人删除、举报 |
| 我的衣柜 | 收藏列表、备注搜索、备注修改与移除；重复收藏或穿戴保留原有备注 |
| 角色管理 | 新增、改名、删除、从衣柜穿戴皮肤/披风、清除穿戴、反查当前外观 |
| 用户中心/账号 | 账号概览、登录/注册/退出、邮箱验证申请、改密、改邮箱、注销 |
| 账号恢复 | 找回邮件申请、一次性凭据验证/重置表单；后端邮件链接仍使用 `/account-recovery` |
| 管理后台 | 用户列表、封禁/解禁、所有者授予/撤销管理员、举报处理/驳回、材质上架/下架、审计记录 |
| 接入指南 | 认证根地址与复制、authlib-injector 接入步骤 |

下架条目会被后端同时从详情和个人列表隐藏。管理员可在审核页按 UUID 恢复；持有原详情地址的上传者可删除自己的条目。服务器校验权限，前端不放宽访问控制。

积分、签到、站点运营配置、本站 OAuth2 授权及第三方 OIDC 登录已接入 Go 原生接口；不提供 PHP 插件运行时。

## 运行

已实测 Node.js 24.21.0、npm 11.19.0、React 19.3.1、Vite 8.3.4、TypeScript 7.0.2、skinview3d 3.4.2。

```powershell
npm ci
$env:YGG_BACKEND_URL = 'http://127.0.0.1:18080'
npm run dev -- --port 5173
```

打开 `http://127.0.0.1:5173/web/` 即公开首页；皮肤库为 `#/library`，用户中心为 `#/dashboard`。Go 后端须独立启动并完成迁移；配置见同级 `YggServer-Go/README.md`。前端不读取数据库或 Redis 凭据。

开发代理转发 `/api`、`/textures`、`/healthz`、`/readyz`、`/authserver`、`/sessionserver`、`/account-recovery`。开发环境接入指南默认显示代理目标的根地址。可通过 `YGG_PUBLIC_API_ORIGIN` 或 `VITE_PUBLIC_API_ORIGIN` 覆盖指南中的公开根地址。

```powershell
npm run typecheck
npm run test
npm run build
```

测试使用 Node 内置测试运行器，不另加测试框架。覆盖上传尺寸/模型、密码字节与角色名约束、分页头和整数类型映射。

构建后设置后端 `YGG_WEB_DIR` 为本目录下 `dist` 的绝对路径，再启动 Go 服务，即可从后端 `/web/` 访问。采用 hash 路由，直接刷新深层页面不需要服务端 SPA 回落。API 路径均为绝对路径。

## 实现约束

- `src/api/client.ts` 统一请求与错误映射；令牌仅存 `sessionStorage('ygg.session.token')`，存储不可用时退回内存。401 或回查账户确认失效的 403 会清空会话，普通越权 403 不误退出。
- `src/api/resources.ts` 复用同一资源接口，列表统一携带鉴权并读取响应头分页。没有仿造 Blessing Skin 的 PHP 响应结构。
- `src/components/` 复用按钮、字段、原生模态框、提示、分类、分页、状态、材质卡片与图像展示；页面负责取数。模态框使用浏览器原生焦点约束、Esc 和焦点归还。
- `src/styles/tokens.css` 集中定义主题、颜色、尺寸和间距；`src/i18n/zh-CN.ts` 集中文案；`src/api/enums.ts` 集中整数类型映射。
- 3D 使用已批准的 skinview3d，独立动态加载。终版主 JS 约 292 KB，3D 包约 517 KB（gzip 约 129 KB），因此 Vite 会给出单包超过 500 KB 的体积提醒。3D 包包含 Three.js 渲染器，不进入首页主包。私有、下架或披风使用平面预览；WebGL 创建失败可退回平面。
- 无运行时 mock；浏览器验收数据只存在隔离测试数据库。未增加后端接口、修改迁移或改变鉴权协议。

## 站点运营与外部授权

- `#/points`：积分余额、滚动签到间隔、下一次可签到的本地日期与时间、最近 50 条流水；不足与冷却错误由统一 client 映射。
- `#/admin/site`：仅站点所有者可保存完整配置和管理 OAuth 公共客户端。名称、简介、公告、注册、邮箱域名白/黑名单、材质域名、角色上限、同类单会话、签到及消费价格、OAuth 服务开关、OIDC 提供方均由 `/api/site` 读取。后端强制规则，前端展示规则并限制可操作入口；减少角色上限不删除已有角色。
- `#/oauth/authorize`：展示本站 OAuth 应用名称、精确回调与 User.Read/Player.Read 权限，同意或拒绝后回到应用。账号页查看和单独撤销授权；外部 OAuth token 不作为本站 Web 会话。
- 登录页提供配置后的 OIDC 按钮；账号页可显式绑定和用本站密码解绑。`#/oidc/callback` 在提交前清除 code/state，校验同标签页 sessionStorage 中的发起状态，完成后仅将本站 Web token 存入既有 sessionStorage。提供方令牌与 Client Secret 不进入前端。StrictMode 下用可清理的延后效果确保一次性流程只消费一次。
- 回调为 `YGG_PUBLIC_URL/oidc/callback`；通过该公开地址的 `/web/` 发起 OIDC，避免开发代理与回调 origin 不同导致 sessionStorage 校验失败。密钥通过后端环境配置，不在管理页面输入。新 OIDC 账号若需游戏密码或解绑，先通过 SMTP 邮件找回设置本站密码。

后端规则、迁移、授权参数与费用语义以同级 YggServer-Go README 为准。新增功能不引入前端依赖，复用现有组件、请求、枚举映射与文案系统。
